# CSCI 2906 – Final Project

This repository contains the final project for **CSCI 2906: Software Development**. The project was created to demonstrate the concepts and skills learned throughout the course, including software design, development, and best practices.

## About the Course

**CSCI 2906 – Software Development** covers the principles and practices of modern software engineering, including:

- Software design and architecture
- Version control with Git and GitHub
- Writing clean, maintainable code
- Testing and debugging
- Collaboration and project management

## Project Overview

This final project serves as a culmination of the topics covered in the course. It is intended to showcase the application of software development principles in a real-world context.
